# Speedometer Digital Accessibility

Speedometer Digital is designed so its common speedometer, map, trip, HUD, and
settings tasks can be used across supported iPhone and iPad screen sizes.

The app supports:

- VoiceOver labels, values, hints, and logical navigation for primary controls;
- Dynamic Type and system text-size preferences;
- dark appearance and high-contrast speed displays;
- information that is not communicated by colour alone; and
- the Reduce Motion system preference.
